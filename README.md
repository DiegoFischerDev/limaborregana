# limaborregana.com

Site institucional da **Lima Borregana**, empresa de relocation em Portugal, focada em apoiar estrangeiros e famílias no processo de mudança, integração e legalização no país.

---

## 📌 Sobre o Projeto

Este repositório contém o código-fonte do site **limaborregana.com**, desenvolvido em HTML, CSS e JavaScript, com foco em:

- Apresentação institucional da empresa
- Serviços de relocation em Portugal
- Comunicação clara para clientes internacionais
- Performance, acessibilidade e SEO básico

O projeto foi desenvolvido como um site estático, simples e de fácil manutenção.

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
